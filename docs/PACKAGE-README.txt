SCBL LAN 1.0

使用：完整解压到新目录，运行 SCBL.LAN.exe，选择 Blacklist_DX11_game.exe（仅支持 DX11）。正常使用无需管理员。所有联机玩家及服务端请使用同一完整版本，不要混换 DLL。

目录按用途组织：SCBL.LAN.exe 为启动器；runtime 存放运行组件；package 存放整包校验清单；licenses 存放许可；data 为启动器运行时数据。请完整保留，不单独移动或替换其中组件。根目录不再使用版本号子目录。

本版保留已有存档、鼠标、无人机、滑铲和目镜优化；绝缘鞋改动已撤销，保留狙击鞋原效果。12 人扩展关闭，维持各模式原生人数限制。
热成像直视烟雾时普通佣兵偏淡按游戏特性保留，不再干预；肾上腺素高亮区别保留。电磁镜／热成像转镜在部分场景仍可能卡顿，尚未完成修复效果的实机验收。

遇到问题可用启动器内“导出诊断包”；需要捕获崩溃时可在“高级诊断”中选择“诊断启动一次”和“导出异常现场”，这类转储可能含敏感信息，需单独确认且不会自动上传。专用采集脚本、维护记录和源码不随程序目录分发；源码单独归档。本次发布不会改写旧安装、账号或存档，也不会自动迁移旧目录数据；旧目录请保留。
