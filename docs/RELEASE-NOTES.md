## SCBL LAN 1.0.0

完整 Windows 程序包：启动器、主 DLL、MOD 玩法 DLL、联机服务端，以及必要资源与许可说明。不包含完整游戏。

### 安装与使用

1. 关闭正在运行的游戏和旧启动器，将程序 ZIP 完整解压到新目录。
2. 运行 `SCBL.LAN.exe`，选择游戏的 `Blacklist_DX11_game.exe`。
3. 所有玩家和服务端使用同一完整版本，不要混换 DLL。仅在可信局域网或加密组网环境使用，不要直接暴露公网。

现有账号、配置和存档请先自行备份；默认存档模板不会在正常启动时自动覆盖玩家存档。

### 本版范围

- 包含当前 1.0 的游戏修复与 MOD 内容、按用途整理的运行目录和启动器音乐。
- 默认存档模板采用 2026-10-15 的配置快照。
- 12 人扩展暂时关闭；狙击鞋保留原效果。
- 热成像直接看烟后普通佣兵偏淡，按原生效果保留。电磁镜、热成像在部分场景转镜仍可能卡顿。

构建、核心回归、完整包校验和隔离的启动器／存档模板检查通过后才发布；这不等同于所有多人实机场景均已验收。

下载包附带 `SHA256SUMS.txt` 和 `BUILD-PROVENANCE.json`，可核对文件完整性和云端构建来源。
