SCBL LAN - source and local build dependency notice

The existing upstream GPL-3.0 LICENSE is retained. Native protocol/server code retains its upstream source notices (5th Echelon: https://github.com/unixoide/5th-echelon). This repository organization does not relicense third-party material.

.NET/WPF, Rust crates, Google.Protobuf/gRPC and Tomlyn remain subject to their respective upstream licenses. Cargo.lock and the project files identify build dependencies. The Tomlyn notice is retained in src/launcher/src/ThirdPartyNotices.

The local launcher build also uses music/images, FusionFix, a diagnostic capture executable, an original Ubisoft loader and default save templates. The native audio build uses DirectX SDK headers. These local inputs are listed in scripts/local-assets.json and excluded from the Git index while provenance and redistribution permission are reviewed. Local possession and a successful build are not clearance for public redistribution.

The local validation package is rebuilt from the reorganized source. No VPN client is bundled. Public source and binary publication require separate review of the retained upstream notices and these local inputs.
